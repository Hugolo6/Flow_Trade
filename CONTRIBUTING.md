\# Política de contribución — FlowTrade



1\. Cada cambio debe realizarse en una rama feature/\*.

2\. Todo cambio debe presentarse mediante Pull Request.

3\. Cada Pull Request requiere revisión de otro desarrollador.

4\. No se permiten commits directos a main o develop.

5\. Se prohíbe utilizar git push --force en ramas compartidas.

6\. Solo los desarrolladores designados realizan integraciones.

7\. Los commits deben seguir Conventional Commits.

8\. Cada PR debe relacionarse con una tarea del proyecto.

9\. No deben subirse contraseñas, tokens ni claves privadas.

10\. Los cambios deben incluir pruebas cuando corresponda.
